# ![Icon](icon/icon.svg) ELH Tim's Helper

_One day, Tim started an internship at Erasmus Life Housing and realized that there were too many clicks in his work... so he said:_
> _"Laziness is the engine of progress"_

_and started to develop this extension..._

**ELH Tim's Helper** is a browser extension designed to streamline the creation and editing of rooms, listings and landlords on the Erasmus Life Housing platform. It automates repetitive tasks, fills forms with AI, and parses external data to save time.

## Key Features
- **Additional Buttons**: Extention injects additional buttons to ELH pages to make common tasks faster.
- **AI Content Generation**: Generate room names, descriptions, and address fields using Gemini AI.
- **Universal JSON**: Paste data from external sources into ELH forms with one click.
- **Batch Tools**: Edit big amount of rooms with new data match and match faster.
- **Customization**: Dedicated options page to tweak prompts and settings.
